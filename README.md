# 🐑 伸脖羊飛臺北

**👉 [開始玩](https://kenneth0604.github.io/long-neck-sheep/)**

## 規則

- 點一下，羊頭往上跳；**按越久，跳越高**。不按就會往下掉。
- 羊的身體留在原地，脖子沿著飛過的路線一路伸長。
- 穿過上下臺北地標之間的縫隙，每穿過一組得 1 分。
- 撞到建築、天燈或地面，伸脖羊就會說「晚安！」，遊戲結束。
- 越玩越難：前進速度會慢慢變快，上下縫隙會慢慢變窄。
- 每隔幾組縫隙中間會有 💧 小水滴，集滿 5 顆就進入「洋流衝刺」：加速 5 秒、建築縮小變透明、可以直接穿過。
- 結束後可以輸入名字，把分數上傳到全域排行榜（每台裝置保留最高分）。

電腦上可以用 **空白鍵** 或 **↑** 操作。

<sub>非官方粉絲創作，與任何競選團隊無關。</sub>
